## How I Troubleshoot 

I don't like changing things before I know what the problem is. I usually start with a few basic checks and go from there 

  

1- Understand the problem:  

- Identify  

is it just one problem? one device? all devices? when did it start? what happened before it? 

check what's not working and who is affected 

2- Check possible causes  

-run some basic tests and look for clues remember if we found the problem means we solve it with 50% like halfway to solving the problem 

3- Try a fix  

- start with a simple solution and move on if needed 

and test again see if the problem is actually fixed 

4- Keep a note  

- write down what I tried and what worked. 

## Notes: 

Only use these commands and steps on systems you own or have permission to support. 

Some commands need administrator permissions. 

Check what's causing the problem before changing system settings  

DONT share passwords, company information, or sensitive network details 

Don't assume a cause is correct until you've checked it. 

Check the relevant vendor documentation when needed.
